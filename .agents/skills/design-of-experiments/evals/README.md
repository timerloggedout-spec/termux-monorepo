# Behavioral evaluation protocol
Run each prompt independently with the skill and without it. Keep identical user inputs and tool availability; do not leak the expected output to the task-performing agent. Have a separate reviewer inspect saved outputs and tool traces. Grade each assertion with passed, evidence, and failure reason. Record model identifier, settings, tokens/time when available, tool versions, and prompt version. Include multiple seeds/runs where relevant. Aggregate pass rates without treating one run as proof of general competence. Scientific validity outranks format compliance. These prompts were authored but not run as independent agent benchmarks in this delivery.
