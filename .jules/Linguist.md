## 2026-08-11 - Markdown Preservation in Token Compression
**Learning:** For a robust markdown compiler converting documents between a token-optimized language (CedrLang) and standard human-readable English (and vice-versa), traditional global symbol replacements and stopword stripping lead to lossy translations and break list formats, links, decimals, permissions, and file names. To ensure 100% stable round-trip compilation, we must protect fenced code, inline code, links, HTML, bold/emphasis blocks, file paths, and numbers (including decimals/hex/octal permissions) using unique placeholders on a line-by-line basis before applying token boundary-constrained translations.
**Action:** Use a relative-order placeholder stack to capture and shield protected structures on each line before running regex token substitution, and then restore them afterward in reverse order to ensure stability.
