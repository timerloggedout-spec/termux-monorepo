Delphic Oracle Method

Loading the live panel configuration from master…

1 · Generate n

Each pass generates n proposals from a fetched, provenance-stamped evidence set.

2 · Cross-vote, round 1

Comparative ballots across all n; source classes stay separate; input vote expectations are recorded before implementation.

3 · Implementation comparisons

Parallel per-proposal implementations; tests run per proposal.

4 · Evidence equalization

Round 2 starts every voter from the identical per-proposal test-results bundle (sha256-stamped).

5 · Re-vote, round 2

Second Delphi cycle on the equalized evidence base.

6 · Calibration

Round-2 votes vs round-1 expectations; deltas feed the weights and outcome ledgers.
