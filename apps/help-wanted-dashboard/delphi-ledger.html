How to read this page — the feed’s honesty rules

  • Current state is folded by the gate’s own rule (the newest marker comment’s JSON block, verbatim) in the collector — this page renders that payload as carried and recomputes nothing.
  • Events are the recorded stream from the ledger issues, in feed order, headlines and payloads verbatim; corrections are new events, never edits.
  • Excluded noise is counted per ledger and named on this page; the source of truth stays the issue comments and living bodies themselves.
  • Living records are keyed by version: version_key is the sha256 of the issue body, so a changed body is a new version of the record, stamped at snapshot_at.
