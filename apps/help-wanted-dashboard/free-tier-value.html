Method rules

  • Paid-equivalent = input tokens × input rate + output tokens × output rate, divided by one million.
  • Call it avoided cost only when the session is confirmed no-cost; unknown billing status remains unknown.
  • Headline requires validation_status=VALIDATED, basksweep_status=PASS, and publication_status=PUBLIC_SAFE.
  • Missing data is unknown, not zero. Failed, duplicate, unvalidated or low-confidence sessions cannot inflate value.
  • Never publish prompts, completions, tool payloads, credentials, private quota readings or personal identifiers.
