# ListingLens — D3 · Builder.io Agent-Native Hackathon

**One-liner:** an indie seller photographs an item ⇒ the agent drafts the
whole listing — copy + pricing suggestion + storefront layout — and the
seller views, edits, and acts on every field before it ships.

## The agent's job (real job, per the official brief)

`photo ↦ listing` — implemented end-to-end:

| stage | where | what |
|---|---|---|
| contract | `src/schemas.mjs` | zod: `PhotoInput` ↦ `ListingPackage` (copy ∧ price ∧ layout), `ListingPatch` for edits |
| model | `src/model.mjs` | replaceable interface; default = deterministic local fallback (∅ keys, ∅ network) |
| pipeline | `src/pipeline.mjs` | copy draft ∘ pricing (comparables median × condition, charm-priced; category-baseline fallback) ∘ layout (template by confidence, palette accent, hero→story→details→shipping) |
| actions | `src/actions.mjs` | `defineAction()` × `generateListing` (the job) + `reviseListing` (user acts: patch ↦ new revision, prior never mutated) |
| surface | `src/ListingStudio.jsx` | React: photo + generated package, **every field editable**, Apply-edits routes through `reviseListing`; Regenerate re-runs the agent |

## Run it (offline)

```sh
npm install   # once: @agent-native/core, zod, react
npm test      # 11 tests: pipeline transform + zod contracts + live action runs
npm run demo  # fixture photo ↦ listing ↦ seller edit ↦ revision 2 (deps ∅)
```

Bundled fixture = `fixtures/sample-photo.json` + `fixtures/sample-vase.svg`
(a labeled illustration standing in for a seller photo) — the demo needs
∅ external services, ∅ API keys, ∅ secrets.
