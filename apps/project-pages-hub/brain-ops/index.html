Measurement boundary

Measured: GitHub Actions workflow state, completed-run pass rate and wall-clock duration from workflow start to update.

Unmeasured: production invocation volume, end-to-end latency, model quality/calibration, token cost, specialist utilization, recommendation acceptance, host uptime and task-level verified completion.

This dashboard reads public GitHub metadata. It does not call the Brain runtime or claim private telemetry access. The inventory is a reconciliation view of the subsystem taxonomy and ownership proposal, not a claim that each row is a separate sub-brain.
