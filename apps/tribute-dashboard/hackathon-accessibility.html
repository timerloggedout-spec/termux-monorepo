# Hackathon Desk — Accessibility Guide

## Target

The Hackathon Desk targets WCAG 2.2 AA and supports keyboard, pointer, touch, zoom, responsive reflow and reduced-motion preferences.

## Keyboard use

- Use the skip link to move directly to main content.
- Navigate the primary sections with Tab and Shift+Tab.
- Activate links and buttons with Enter or Space as appropriate.
- Use the opportunity search field with the keyboard.
- Follow the visible focus indicator through every interactive element.

## Screen readers

- Page regions use header, navigation, main, section and footer landmarks.
- Each module has a heading and a stable section identifier.
- Feed health uses a polite live region.
- Source status appears as text labels alongside content.
- Links describe their destination, and external links open with safe rel attributes.

## Zoom and reflow

The layout adapts at tablet and mobile breakpoints. Cards stack into one column on narrow screens, and content remains readable at 200% zoom. Tables and dense evidence should use a local horizontal scroll region when needed.

## Motion and contrast

The page honors prefers-reduced-motion. Status distinctions include text labels in addition to color. Focus indicators use the shared dashboard accent token.

## Manual review checklist

- [ ] Complete the page using keyboard only.
- [ ] Confirm focus remains visible and follows reading order.
- [ ] Inspect at 320 CSS pixels and at 200% zoom.
- [ ] Test with a screen reader and confirm landmarks and headings.
- [ ] Confirm stale, unavailable and invalid feed states are understandable without color.
- [ ] Confirm search and refresh controls expose accessible names.
- [ ] Confirm links use meaningful labels and safe HTTPS destinations.
