SCOPE MODEL

Four independent scopes

  • ProjectRepository, deliverable and contribution boundary
  • EventRegistration, rules, match and submission state
  • VenueExecution requirements, evidence and receipts
  • TeammateCollaboration relationship and assigned responsibilities

A teammate relationship alone grants no event-entry or venue-execution rights.

Contribution path

  1. Read the event rulesConfirm format, eligibility, dates and submission destination.
  2. Choose an existing project or propose a new oneKeep source evidence and verification attached to the intake.
  3. Request the required GitHub accessRepository administrators decide membership and permissions.
  4. Work in a focused branchCommit small changes and open a pull request with evidence.
  5. Review, validate and submitPreserve receipts and verify the official submission destination.
