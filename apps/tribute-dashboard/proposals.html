How this page works

This page renders data/proposals-feed.json (schema proposals-feed/v2; v1 bare-number PR entries still render, without state chips), collected from docs/proposals/registry.yaml and docs/proposals/passes/*/pass.json by scripts/proposals/proposals_feed.py (contract: docs/ops/PROPOSALS-FEED.md). The collector runs on every push to docs/proposals/** and proposes the refreshed feed as a PR. Registry values are carried verbatim; where the feed is empty, nothing is shown rather than anything guessed.
