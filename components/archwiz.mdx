ArchWiz is the central automation cockpit of the Termux Monorepo. It provides 28 specialized tools organized into 7 categories, giving you a unified interface for forensic analysis, autonomous task execution, verification, and knowledge management. Launch the cockpit from the repository root to access the interactive dashboard.

## Launch the cockpit

```bash
python3 archwiz/archwiz.py
```

When you run this command, ArchWiz opens an interactive dashboard with 16 primary options and 3 mode toggles that let you switch between operational contexts without leaving the cockpit.

## Quick commands

ArchWiz also exposes several shell-level shortcuts you can run directly from the repository root without opening the dashboard:

```bash
archaeo <file>           # Research file history and provenance
oracle <file>            # Check impact before making a change
dispatch <task>          # Make a change through the autonomous runner
validate_promotion.py    # Validate and promote a change through gates
```

## Dashboard modes

The cockpit offers 3 mode toggles that change the visible toolset and default actions:

1. **Forensic mode** — Surfaces timeline, correlation, and fragment tools
2. **Autonomous mode** — Prioritizes runner, dispatch, and narrative tools
3. **Verification mode** — Highlights sentinel gates and validation workflows

Switch modes at runtime to adapt the cockpit to your current task without restarting.
