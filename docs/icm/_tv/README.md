# ICM CCTV Board Artifacts

## Scope and authority

This directory owns the monorepo's **file-backed ICM visual review layer**. Markdown cards mirror reviewed ICM state for a human-facing board. The cards remain repository artifacts and stay readable without a renderer.

> **Canonicality rule:** Each card is a visual mirror. Its `source:` frontmatter path identifies the repository-native ICM record that remains authoritative for decisions, routing, governance, and maintenance.

| Provider polling | Unconfigured |
| Interactive response writer | Unconfigured |

## Screen and card rules

1. One card represents one meaningful ICM outcome, decision, status, or checkpoint.
2. Every mirror card uses a repository-relative `source:` path under `docs/icm/`.
3. The publisher validates each canonical source path and card identifier before rendering.
4. Humans own future layout metadata; card authors update the canonical Markdown cards.
5. Interactive response files stay under `_tv/responses/<screen>/<id>.md` and require a named consuming process, accepted values, human authority, and a defined no-response behavior.
6. A blocked checkpoint routes the next step to its named human reviewer and preserves the canonical ICM evidence trail.

## Static publication

The existing Tribute publisher generates the board from canonical Markdown cards and publishes it at the route above. The page uses shared Tribute navigation and styling. The Project Hub and sitemap expose the same canonical route.

The static board provides card search, status filtering, stage navigation, canonical-source links, and review-sequence guidance. Its client-side interactions operate on the generated page content.

The publication serves generated HTML only. The reference renderer's file watching and WebSocket loop remain a separate future capability. Provider polling, response writing, device access, and runtime routing changes remain outside this publication contract. The board also remains separate from the ML lane-projection contract.

## Validation

Run the focused contract with:

```sh
python3 scripts/build_icm_cctv_board.py --check
python3 tests/test_icm_cctv_board.py
```
