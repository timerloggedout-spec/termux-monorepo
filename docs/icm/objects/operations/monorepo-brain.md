**Brain is the monorepo-wide consciousness / cognitive coordination layer.** The root Rust kernel is its shared typed reasoning core; this object describes the wider subsystem architecture and staged integration roadmap.

## Ownership boundary

Brain coordinates cognition, context, research, capability discovery, planning, and feedback. It delegates admission to QUE, authorization to existing policy owners, execution to existing Harness/Hands, persistence to existing memory systems, and verification to evidence-led and domain validators.

It must not create a second queue, scheduler, identity registry, provider catalog, policy engine, memory database, relationship graph, or authoritative evidence ledger.

## Subsystems

Identity/intent; perception/ingestion; context; knowledge/memory; repository ontology; research intelligence; capability discovery; reasoning/synthesis; decomposition/planning; simulation/prediction; policy/safety/authority; orchestration coordination; execution interface; verification/evidence; observability/explainability; adaptation/learning; resilience/resources; security/adversarial defense; multi-agent/swarm; domain cognition; owner experience.

## Delivery phases

P0 ownership/source reconciliation → P1 kernel hardening → P2 read-only knowledge adapters → P3 capability/ontology map → P4 shadow QUE/QDesk handoff → P5 separately authorized vertical slice → P6 measured learning loop → P7 owner cockpit → P8 controlled bounded autonomy.

## Validation

A Brain reasoning run is not task completion. A QUE admission is not execution. A workflow success is not TASK_PASS. A Delphi award is not runtime activation. Each transition requires its own owner, receipt and evidence.
