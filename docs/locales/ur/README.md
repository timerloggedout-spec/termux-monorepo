# اردو دستاویزات

یہ اردو دستاویزاتی راستہ منصوبے کی مقامی زبان میں رہنمائی اور منظور شدہ ترجموں کے لیے مخصوص ہے۔

ابتدائی ترجیح Teammate Portal ہے۔ اس مرحلے میں پورٹل کے بنیادی انٹرفیس لیبل اردو میں دستیاب ہیں؛ منسلک تجاویز اور تکنیکی دستاویزات اپنے اصل انگریزی متن کے ساتھ رہتی ہیں، اور ہر صفحے پر اصل زبان واضح رکھی جاتی ہے۔

ترجمے کی حیثیت، ماخذ کی شناخت، نظرثانی، اور اشاعت کا ریکارڈ localization/ کے رجسٹری، میپنگ، اور مینی فیسٹ میں محفوظ ہوتا ہے۔
