## Root cause

The public user-site mirror is generated by `.github/workflows/tribute-dashboard-deploy.yml`. The workflow copies the monorepo's Tribute and Matrix source into the website repository. Source-owned fixes therefore belong in `apps/tribute-dashboard/`; direct edits to generated mirror copies are temporary.

## P8 release contract

Every published page carries a meaningful Open Graph description:

`<meta property="og:description" content="A page-specific summary of at least 50 characters">`

The source validator checks the content value, canonical URL, meta description, JSON-LD, Markdown alternate, llms.txt discovery, glossary navigation, and static accessibility structure.

## Deployment verification

1. Merge the source PR through the repository's accepted proposal and dual-gate process.
2. Observe `tribute-dashboard-deploy.yml` and capture the workflow run ID.
3. Verify the published `/tribute/`, `/matrix/`, and homepage HTML and Markdown representations.
4. Run Agent Ready against the public origin and inspect P11, P13, P18, and P19.
5. Compare raw HTML bytes, browser DOM size, and visible text length when P13 differs from the source validator.
6. Record the new score, scan ID, page count, llms.txt score, accessibility score, and remaining checks.

## Badge threshold

Publish the Agent Ready badge only after a fresh scan receipt confirms a score of at least 95/100. Keep the score, scan URL, and verification timestamp together as the badge evidence.
