# DO Statement Contract — Review-Only Candidate

**Candidate profile:** adaptive DO syntax with non-blocking style review.

Natural imperatives and explicit `DO:` markers are equivalent accepted forms. Essential prohibitions remain valid constraints.

The validator keeps imperative commit subjects as a hard requirement. It reports a narrow set of hedged openings as `REVIEW` findings while preserving a successful gate result. This profile favors low-friction adoption and produces evidence for later severity calibration.

Examples:

- `Create the artifact.` — accepted.
- `DO: create the artifact.` — accepted.
- `Do not overwrite the canonical standard.` — accepted constraint.
- `We should probably update the validator.` — non-blocking review finding.

The hard-gate candidate instead blocks the narrow hedging set. Compare both profiles against the same replay corpus before selecting a severity.

Siglary taxonomy, notation registration, N∅ boundaries, receipt adjacency, exemptions and hard-gate rules remain governed by the canonical Siglary Standard.
