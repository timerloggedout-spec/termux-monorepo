# Equivalence-Proof Standard (v0)

For OPEN-EQUIVALENCY builds: free/open materials walked
against a gated credential's syllabus, with equivalencies
PROVEN — not asserted. Owner-named method type
2026-11-03. Method holder: the Certifications lane.
Instance #1: SFI ABM. Registered in
`docs/ops/DOE-FAMILY.md` (Method versions) alongside the
lens material.

## The standard

An equivalency claim is **PROVEN** only when ALL of:

- **(a) Syllabus of record.** The target credential's
  requirements decompose from the ISSUER's syllabus
  source itself — not a summary, review, or third-party
  outline. No issuer source, no decomposition, no claim
  above CLAIM-grade.
- **(b) Total mapping.** EVERY decomposed requirement
  either (i) carries a mapping to a RESOLVABLE open
  source (the material exists and can be fetched/read),
  or (ii) sits in the GAP REGISTER BY NAME. Unmapped and
  unregistered requirements do not exist for the claim —
  silence about a requirement is a defect, not coverage.
- **(c) Executed verification.** The verification leg
  EXECUTED artifacts from the open materials — worked
  the exercises, ran the labs, produced receipts. A
  mapping to materials nobody has executed is an
  intention, and intentions verify nothing (the EGM
  oracle order applies: source → served → executable).
- **(d) Stated boundary.** The claim states its boundary
  in its own text: LEARNING-equivalence is what gets
  proven; CREDENTIAL-equivalence is NEVER claimed. The
  gated credential remains the issuer's to award; an
  open-equivalency build proves the learning path covers
  the syllabus, nothing more.

Anything short of (a)–(d) = **CLAIM-grade**, stamped as
such wherever the claim appears. CLAIM-grade is a lawful
state (intake), not a failure — presenting CLAIM as
PROVEN is the failure.

## Coverage reporting

Coverage is reported PER REQUIREMENT CLASS — never as a
single percentage over unlike classes (K9 parity
discipline, ATES-IMPROVEMENT-FRAME: a coverage claim
without per-stratum n is non-conformant). Each class
reports {requirements · mapped · gap-registered ·
executed-verified} from the claim's own record.

## Stamps

```
{equivalency_claim: {target_credential, syllabus_ref
 (issuer source), standard: "equivalence-proof/v0",
 state: PROVEN|CLAIM, gap_register_ref (when any gap),
 boundary: "learning-equivalence only"}}
```

A PROVEN stamp without all four legs resolvable from
the claim's record is void on inspection.
