# Profile Registry — Fleet Public Identities

Tracks every public profile the fleet generates or uses on external
platforms, organized **hierarchically by owning lane**. This document is the
source of truth; the Google Sheet
["Profile Registry — Fleet Public Identities"](https://docs.google.com/spreadsheets/d/1cExL5Ikv06OUzhDPkSgOnlRpGV_QQ-kqsPrJFJjgeAk/edit)
is its at-a-glance view and is refreshed from here.

**Rules**

- A profile is registered under the lane that uses it. New lanes add their
  section; nobody registers a profile into another lane's section.
- Public-field style (owner directive, 2026-10-26): **obfuscated | obtuse |
  cryptic | 1337 | anonSEC** — public fields carry no identifying content
  beyond what is already public fleet identity.
- Field states are evidence-based (verified from the platform or its terms),
  never assumed. The card is a BLOCK everywhere: no card-gated signup is ever
  completed to finish a profile.
- Credentials never appear here — names/handles and field states only.
