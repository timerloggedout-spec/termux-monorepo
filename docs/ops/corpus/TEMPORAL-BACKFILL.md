# Context Relationship Historical Backfill — L1/L2 Operating Contract\n\nThe context relationship backfill has two durable layers:\n\n1. **L1 relationship corpus** — current normalized nodes, edges, evidence, and coverage.\n2. **L2 temporal evidence** — immutable observations, structural deltas, and lineage.\n\n## Backfill sequence\n\n```text\ncanonical master\n     │\n     ├── bounded page window\n     │\n     ▼\nL1 compile\n     │\n     ├── nodes / edges / matrix\n     │\n     ▼\nL2 snapshot\n     │\n     ├── snapshot_id\n     ├── source SHA/ref\n     ├── page bounds\n     ├── coverage\n     ├── content hashes\n     └── delta from prior observation\n     │\n     ▼\nappend lineage\n     │\n     ▼\npublish current materialized corpus\n```\n\n## Continuation\n\nThe workflow is anchored to `master`, not the historical `master-staging` branch.\n\nWhen no explicit page is supplied, the workflow reads:\n\n`workspace/llm_map/context_relationships/manifest.json → history_window.next_start_page`\n\nand resumes from that page.\n\nA page window does not imply global completeness. Continue until the collector reports `next_start_page: null`.\n\n## Promotion and preservation\n\nNever:\n\n- merge a stale staging branch wholesale;\n- overwrite an existing temporal snapshot;\n- infer completeness from node/edge growth;\n- convert missing evidence into zeroes;\n- collapse candidate relationships into verified facts;\n- treat a dashboard projection as the source of truth.\n\nEvery temporal snapshot retains its source SHA/ref and page bounds.\n\n## Review surface\n\nUse:\n\n```bash\npython -m pytest tests/test_context_relationship_*.py -q\n```\n\nThe temporal-specific contract is:\n\n```bash\npython -m pytest tests/test_context_relationship_temporal.py -q\n```\n\nInspect:\n\n- `build-summary.json` for `snapshot_id`, `previous_snapshot_id`, `coverage`, and `delta`;\n- `temporal-current.json` for the latest immutable observation descriptor;\n- `temporal/lineage.jsonl` for the append-only observation chain;\n- `temporal/snapshots/<snapshot_id>/` for exact graph artifacts.\n\n## Downstream use\n\nSHE may use L2 to render longitudinal coverage and graph deltas.\n\nResearch/3L0 may use L2 to freeze cohorts and reconstruct historical context.\n\nNeither consumer may rewrite L1/L2 evidence or turn heuristic candidates into asserted facts.
