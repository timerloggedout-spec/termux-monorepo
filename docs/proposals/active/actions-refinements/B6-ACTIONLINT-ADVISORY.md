# B6 — Advisory GitHub Actions Lint Pilot

**Status:** Implemented as an advisory control on `fix/ar01-automation-baseline`; pending pull-request checks and reviewer assessment.
**Ledger item:** X-01 / B6
**Workflow:** `.github/workflows/actionlint-advisory.yml`

The B6 pilot adds a narrow workflow-syntax and expression check for changed GitHub Actions surfaces. It is advisory only: it has no auto-fix step, no pull-request comment path, no dispatch path, and no write permission. The branch-protection policy must not promote it to a required check until the baseline findings below are dispositioned.

## Candidate Review

| Criterion | Review result |
|---|---|
| Tool | `rhysd/actionlint` v1.7.12 at immutable commit `914e7df21a07ef503a81201c76d2b11c789d3fca`. |
| License | MIT. |
| Maintenance signal | The repository was not archived and had GitHub activity in July–August 2026 when reviewed. |
| Invocation | This revision is a Go project and Docker image rather than a root Marketplace-action manifest. The workflow fetches and verifies the exact commit, then builds `./cmd/actionlint`; it does not use a mutable action tag or `curl | bash`. |
| First-party dependencies | `actions/checkout` v5 and `actions/setup-go` v5 use immutable 40-character commit SHAs. Checkout disables persisted credentials. |
| Permissions | Workflow scope is `permissions: {}`; the sole job receives `contents: read`. |
| Trigger | Pull requests affecting `.github/workflows/**`, `.github/actions/**`, or an `actionlint` configuration file, plus controlled manual dispatch. |
| Rollback | Delete `actionlint-advisory.yml`. It owns no state, artifacts, secrets, labels, comments, or external dispatches. |

## Baseline and False-Positive Review

The v1.7.12 Linux AMD64 release archive was SHA-256 verified against the release checksum file before the local baseline run. The new advisory workflow itself produced **no actionlint finding**. The local release-only run found 20 findings across six pre-existing/generated files. The authoritative GitHub-hosted advisory run found 26 findings across eight pre-existing/generated files because the hosted Ubuntu runner also supplied ShellCheck integration.

| Affected file | Findings | Initial disposition |
|---|---:|---|
| `agent-jules-on-issues.yml` | 3 | Existing unsupported use of the `secrets` context in step-level `if` expressions. Actionable outside this B6 rollout. |
| `agent-review-auto-jules.yml` | 6 | Existing malformed step structure around `uses` / `with`, plus hosted ShellCheck findings. Actionable outside this B6 rollout. |
| `gemini-dispatch.yml` | 3 | Existing reusable-workflow input mismatches. Actionable follow-up; not modified in this B6 batch. |
| `gemini-invoke.yml` | 8 | Existing undefined reusable-workflow inputs. Actionable follow-up; not modified in this B6 batch. |
| `gemini-triage.yml` | 2 | Existing call-surface mismatch findings. Actionable follow-up; not modified in this B6 batch. |
| `agentic-repository-operations-report.lock.yml` | 2 | `queue: max` generated by `gh aw` v0.86.2 is unknown to actionlint v1.7.12. Treat as a tool-compatibility candidate, not a waived finding, until a newer actionlint release or compiler guidance resolves it. |
| `proposal-lifecycle.yml` | 1 | Existing ShellCheck style finding (SC2129). Review separately; it is not a B6 workflow defect. |
| `context-relationship-backfill.yml` | 1 | Existing hosted ShellCheck finding. Review separately; it is not a B6 workflow defect. |

The all-workflow local lint scan completed in less than one whole second of shell-resolution time after the verified release executable had been unpacked. The first GitHub-hosted advisory run completed in 26 seconds end-to-end; its pinned build finished at 06:13:39 UTC and the lint command concluded at 06:13:41 UTC. The hosted measure includes runner provisioning and the pinned Go build, and is therefore the relevant CI cost observation. The workflow reports up to the first 200 lint lines in the job summary and remains non-blocking while the baseline is reviewed.

## Promotion Decision

Do **not** promote this check to required status yet. Keep it advisory until reviewers disposition the existing baseline findings, validate the two generated-lock compatibility findings, and compare GitHub-hosted runtime with the available CI budget. Remove the workflow if the lint signal cannot be maintained with a pinned compiler/tool version or if its false-positive rate is not acceptable.
