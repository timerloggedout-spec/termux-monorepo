# Superseded Notation Draft

This draft's `grimoire.siglary-bridge.v1` namespace and recipe-specific shorthand are withdrawn. Grimoire is existing repository vocabulary; Siglary is an existing issued notation system governed by Linguist. This project has no authority to create a competing notation dialect or reserve operators.

The neutral project does not require compact notation for its initial phase. If a later use case justifies notation, it must be proposed through the existing Siglary/Linguist registry with collision review, semantics, parser fixtures, round-trip tests and explicit issuance.

Current package: [Software Recipe Intelligence](../software-recipe-intelligence/README.md). No notation profile is adopted.
