# ELI5 — doe-methods-map.mmd

**What the diagram shows:** eight named methods — the standard
ways this program runs an experiment — and, above them, the
four-part form every method must be written in.

**What it means, in plain words:**

- A "method" here is not a vague approach. To count as a method,
  it must answer four questions in writing: What does it test?
  How is it set up? How do we decide if it passed? Where is the
  proof it actually ran?
- The eight boxes are the eight methods that were really used
  this period — things like "check a scoring machine by replaying
  its own records," "never trust a count from only one source,"
  and "test the whole pipeline live on one real case before
  trusting it."
- The strip at the bottom is the loop every experiment travels:
  write the plan first, build, check, get a second check, decide,
  record, then either add a layer or close.

**What the diagram does NOT show:** the insides of any method —
how each test works, what counts as passing, or the receipts.
Those are the actual content, and they live in the methods
document this picture summarizes. If a box here and the document
ever disagree, the document wins.
