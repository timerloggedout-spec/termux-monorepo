# Name and Collision Register — Software Recipe Intelligence

**Status:** candidate register; no name is issued or reserved.  
**Naming authority:** existing repository naming process (Name Forge / Grimoire and Linguist/notation governance as applicable). This document is an evidence register, not a competing naming authority.

## Naming rule

Keep the descriptive research phrase **Software Recipe Intelligence** separate from the eventual proper name and acronym. Do not turn the phrase into `SRI` as the public acronym: the same acronym is strongly associated with SRI International (formerly Stanford Research Institute), whose AI research produced the Siri spinout. SRI's own history documents the Siri spinout in 2007. This is a material identity/search collision even though the proposed expansion would be different.

The model abbreviation **SRM** means Software Recipe Model. It names the data model, not the project, system, runtime, or owner.
