What is implemented

01

Bayesian inference

Beta-Bernoulli posterior, equal-tail credible intervals, predictive Beta-Binomial PMF and moments.

02

Information theory

Beta entropy, KL divergence, expected information gain, and decision-optimized binary EVSI.

03

Graph algorithms

Kahn ordering, DAG longest path, general-DAG maximal common ancestors, and three-way reconciliation.

04

Markov economics

Explicit normalized transition propagation, terminal probability mass, and expected accumulated edge costs.

05

Numerical discipline

Log-domain predictive probability, finite-value validation, compensated sums, deterministic tie-breaking and provenance digests.

06

Review admission

Uncertainty, regression, anomaly density, provenance gaps, change points and decision impact inform when review is warranted—not who wins.

Governed integration

QUE autonomous · observe first

The integration proposal (#5225) treats Delphic as an opt-in, read-only evaluation adapter. QUE retains queue admission, claims, dispatch and lifecycle. Existing evidence schemas and execution workflows remain authoritative.

  • No queue mutation or provider dispatch from an Observatory result.
  • No credentials, branch writes, merges, or promotion authority.
  • Stable task/attempt/run/SHA/evidence references; missingness is preserved.
  • Schema validation, deterministic fixtures, feature flag and rollback before operational adoption.

Mathematical engineering boundary

Wolfram → symbolic derivation and challenge → mathematical contract → local deterministic implementation → hosted CI.

Wolfram improves formula quality; it is not a runtime calculator or dependency. Production reference calculations use local Python standard-library code.
