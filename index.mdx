The Termux Monorepo is an Android-native automation platform that orchestrates AI-powered development workflows through specialized CLI tools and autonomous agents. Built for Termux, it integrates with the DeepSeek API, manages conversation branching, performs code forensics, and maintains comprehensive knowledge indices so you can develop anywhere from your mobile device.

## What the monorepo contains

The Termux Monorepo is organized around six key components that work together to provide a complete automation environment on Android.

  <Card title="ArchWiz" icon="gauge" href="/components/archwiz">

  </Card>

  <Card title="DeepCLI" icon="message-square" href="/components/deepcli">
    DeepSeek-oriented CLI for creating sessions, sending prompts, exporting conversations, and managing branches.
