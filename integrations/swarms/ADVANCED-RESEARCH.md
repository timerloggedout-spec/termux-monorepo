# AdvancedResearch pinned runtime — THUB-017.A / #1522

Upstream `The-Swarm-Corporation/AdvancedResearch` is pinned at `a262cb9d9703681c5a5066f03eb9fb89ad4d9cae`. Vendored source is hash-verified (implementation, prompts, license, and manifests) before each execution. The adapter uses the pinned `AdvancedResearch.run` orchestration; it is **not full Swarms SDK parity**. Swarms, Agent, dotenv, search, and inference are dependency facades.

Execution is opt-in (`enabled=True`) and uses a forked, killable worker. The pinned director Agent invokes inference to obtain JSON `queries` (1..agent budget, max 3; each at most 500 characters), then calls the actual pinned `execute_worker_search_agents`; each pinned worker Agent invokes injected search and inference with bounded evidence in its messages. Callback calls occur in that same worker, not precomputed in the parent. Execution requires an explicit model keyword; callbacks receive `(model, messages, max_tokens, correlation=...)`. Integer token budgets (max 2048) must cover the director plus each configured worker and are split across those calls. Correlation request indices are stable: director 0 and worker i uses i+1, independent of completion order. Search concurrency and outputs are bounded, results are aggregated in submission order, and result text is capped. No live/provider/paid calls are made by tests.

The parent polls cancellation/deadline and terminates, then force-kills if needed, and reaps the worker; the child changes into a temporary working directory that is cleaned on exit, the child clears its environment, and dotenv is a no-op. Source hashes are verified in the parent and again in the child immediately before import; synthetic package loading prevents an unverified initializer from executing. Source verification fails closed. Arbitrary upstream failure details are not returned, avoiding accidental stderr/secret disclosure. This process boundary is containment, not an OS security sandbox; only verified pinned source should be executed. A synchronous callback cannot be interrupted independently; it is stopped by terminating the whole worker.

`pytest -q tests/test_advanced_research_runtime.py` covers genuine pinned orchestration with deterministic fakes, director-generated queries, search evidence passed to worker inference, tampering, deadline/cancellation, and disabled/import behavior. The adjacent hub TestClient suite exercises quota admission/reconciliation and terminal telemetry with the adapter integration.
