# Scavenge templates

One directory per fork/upstream. **Metadata only** (README + SOURCE.txt). No git submodules here by default.

Agents with access to private `timerloggedout-spec/*` forks should fill SOURCE.txt with:

- canonical remote URL
- upstream origin (if known)
- license note
- 3–5 bullet “steal these patterns” list
- explicit non-goals (what not to copy)
