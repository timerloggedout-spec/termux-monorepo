# Shared Equipment and Laboratory Registry

This registry models equipment shared across owned projects and grant-funded work. Asset records carry capabilities, custody, facility, operating limits, operator qualifications, safety controls, calibration, maintenance, availability and grant constraints.

The initial AutoMataLabs program record is a concept reference. The inventory remains empty until actual assets are registered from verified owner records.

Reservations bind an asset to a stable project ID and optional grant references. Facility approval, operator qualification, safety review and cost allocation are explicit fields. The registry stores opaque secret references for serial-level or protected identity data.

See asset.schema.json, reservation.schema.json and registry.yaml.
