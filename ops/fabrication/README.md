# Fabrication and Professional Service Directory

The provider registry is a structured directory for verified fabrication, prototyping, testing and specialist services. Provider discovery begins with candidate records; identity, capabilities, terms and applicable qualifications are reviewed before approval.

Quote requests and paid orders remain user-authorized. Biological laboratory services use licensed providers and applicable professional, biosafety and ethics review.

The initial registry is empty pending provider discovery and verification. See provider.schema.json and registry.yaml.
