🛡️ Sentinel Security Patch

🚨 Severity: HIGH
💡 Vulnerability: Sensitive config data, Bearer tokens, SQLite databases, and telemetry logs containing session states were created with lax default umask permissions, leaving them readable by other local accounts.
🎯 Impact: Local exposure of authentication credentials, active chat messages, and agent command histories in shared or multi-user environments.
🔧 Fix:
- Restrict config directory `~/.deepcli` and cache directories to `0o700` and `config.json`/cached files to `0o600` in `deepcli/deepcli/core.py`.
- Introduce a symlink-safe recursive directory walk in `deepcli/deepcli/cli.py` to lock down chromium profile `browser-data` permissions to `0o700`/`0o600` securely.
- Secure SQLite database (`local_repo.db`) and telemetry log (`agent_telemetry_stream.json`) permissions to `0o600` in `termux-multi-agent/src/db.py` and `telemetry.py`.
- Apply try-except wrappers around chmod calls to fail securely on unsupported or read-only filesystems.
✅ Verification: PYTHONPATH=termux-multi-agent pytest tests/ passes completely.
