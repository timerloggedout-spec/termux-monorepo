# refTemplates Recovery Skeleton

This directory is a metadata-only skeleton to help restore the refTemplates tree safely.

For each subproject there is:
- README.md → short description + restore hint
- SOURCE.txt → preferred source (prefer user's *_fork if present) or a GitHub search URL to find upstream

Do NOT commit secrets. Follow the recovery steps in the top-level repo README before performing recursive submodule operations.
