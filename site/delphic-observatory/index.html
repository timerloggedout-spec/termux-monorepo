Authority boundaries

Read-only projection

  • Canonical evidence remains authoritative.
  • No telemetry emission or gate override.
  • No context graph mutation or promotion authority.
  • Wolfram supports symbolic derivation/review; runtime math is local stdlib-only.
  • Offline Termux is not assumed available; local target validation is explicitly pending.

Autonomous integration

Integration targets are QUE governor and AutonomousOpsStuff, via bounded read-only evidence consumers and explicit dispatch receipts—not a new competing orchestrator.

  • QUE: candidate evidence windows and decision packets.
  • Governor: policy, timebox and approval remain upstream.
  • Feeds: immutable run refs, input hashes, provenance and status.
  • Adversarial review: dynamic admission from telemetry/benchmarks.
