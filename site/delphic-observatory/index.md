# Delphic Observatory

> Live, read-only control room for research lanes, engineering delivery and evidence provenance.

## Platform
GitHub owns canonical source, lane architecture, schemas, issues, pull requests and Actions receipts. Vercel and GitHub Pages serve static UI. Render provides optional free-tier feed caching after plan and health review.

## Research lanes
The matrix covers 14 families: foresight radar, AI technology, science research, FOSS developer tools, emerging technology, agent observability, multi-agent evaluation, reproducible environments, local edge/ARM/Android, agentic security, malware reverse engineering, provenance/supply chain, accelerators/materials/energy, and procurement opportunities.

## Spatial model
LEFT = evidence field. NOW = decision windows. RIGHT = DAG/trellis/Markov interthreading.

## Live feeds
The browser reads public GitHub pull requests and Actions runs. It reports observation time, freshness and degraded states. The feed is read-only.
