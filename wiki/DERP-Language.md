# DERP / d3rp language

**Status:** competing draft specifications · 0.1.0 · 2026-11-23

DERP is the playful public dialect and discovery experience for the Termux monorepo. It helps newcomers learn the project's leetspeak, symbols, rePointers, wiki, and capability surfaces through an exploratory entrance.

## Three cooperating layers

1. **Surface** — readable public copy, canonical links, semantic HTML, Markdown, and search metadata.
2. **Play** — clues, decoys, riddles, visual transformations, and optional invisible-character experiments.
3. **Resolution** — a versioned rePointer registry that maps clue IDs to validated destinations and capability descriptions.

## Invisible-character experiments

Invisible Unicode may provide optional puzzle texture. Each clue keeps a visible label, accessible description, and canonical destination. Clues remain inert data and carry no hidden instructions for crawlers, external LLMs, or user agents.

The public Agent Ready representation uses the plain surface and canonical links. The public site remains useful after all invisible marks are removed.

## Public discovery maze

The planned entrance is a separate public web experience. Its job is to teach DERP to newcomers and reveal documented project capabilities through progressive discovery. The entrance remains a navigation and education layer; repository docs and validated capability records remain authoritative.

The domain, hosting target, visual direction, and first set of discovery paths remain open design decisions.

## SEO and crawler policy

Use visible, useful descriptions and stable links for search discovery. Keep robots.txt as a standard crawler policy file and llms.txt as a factual index of public resources. Agent Ready remains a separate plain-text output profile.
